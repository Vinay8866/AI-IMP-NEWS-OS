# Google Explains How To Use HTML Sitemaps For SEO via @sejournal, @martinibuster

**Hook:** Think HTML sitemaps are dead? Google says otherwise. Discover why this "old school" strategy still holds value for SEO in the age of XML.

Google has clarified the continued relevance of HTML sitemaps in its latest SEO guidance. While XML sitemaps remain the primary tool for helping search engines discover and index site structure, Google’s recent explanation notes that HTML sitemaps still serve a distinct purpose for user navigation and site accessibility. The guidance, published by Search Engine Journal, emphasizes that HTML sitemaps are not a replacement for XML but can complement it, particularly for larger sites or those with complex navigation hierarchies. The search engine’s stance aligns with long-standing SEO best practices: HTML sitemaps improve how visitors find content, which can indirectly influence engagement metrics. Google did not frame them as a direct ranking factor, but rather as a usability tool that supports overall site health when used alongside XML sitemaps. The clarification comes as part of Google’s ongoing effort to help webmasters balance technical indexing with user-friendly site design. Practical takeaway: Include an HTML sitemap if your site has deep pages that are difficult to reach through main navigation, but prioritize XML sitemaps for technical indexing. Regularly audit both to ensure they reflect your current site structure and update them whenever major content changes occur.
